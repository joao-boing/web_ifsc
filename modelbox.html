MODELO EM CAIXA, MODEL BOX HTML

elementos html são estruturados em um modelo denominado modelbox, que refere-se a caracteristica de um elemento pode conter outros elementos, sendo que cada um possui uma estrutura interna similar a ideia de uma caixa dentro da outra

ESTRUTURA DE UM ELEMENTO HTML

Todos os elementos html possuem conteúdo, pading, borda, offset. Sendo a região de conteúdo estruturada em três camadas: 1) background-color 2) background-image 3) content
