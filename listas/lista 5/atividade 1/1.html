O que é JavaScript?

O JavaScript foi criado em 1995 por Brendan Eich, na Netscape, com a motivação de deixar as páginas web interativas, já que o HTML sozinho só mostrava conteúdo estático. Ele pode ser executado no navegador, onde manipula a página e responde às ações do usuário, ou no servidor (com o Node.js), onde acessa arquivos, bancos de dados e responde requisições. No navegador, o JavaScript roda dentro de uma sandbox, um ambiente isolado que impede o código de acessar livremente o computador do usuário, como arquivos e programas, por segurança. O navegador também oferece objetos globais, como o document (acessa e altera a página), o console (mostra mensagens para o desenvolvedor) e o alert (exibe uma caixa de aviso).
