# Atividade 1 - Flexbox Froggy

## Nível 11

```css
#pond {
  display: flex;
  flex-direction: column;
  justify-content: flex-end;
}
```

- `flex-direction: column;` coloca os sapos um embaixo do outro.
- `justify-content: flex-end;` joga os sapos para o final, que nesse caso é embaixo.

## Nível 12

```css
#pond {
  display: flex;
  flex-direction: column-reverse;
  justify-content: space-between;
}
```

- `flex-direction: column-reverse;` coloca os sapos um embaixo do outro, mas na ordem invertida.
- `justify-content: space-between;` espalha os sapos, deixando o mesmo espaço entre eles.
