O que é o protocolo HTTP?

HTTP (HyperText Transfer Protocol) é o protocolo usado na Web para o navegador (cliente) conversar com o servidor. O navegador faz uma requisição (request) pedindo uma página e o servidor devolve uma resposta (response) com o conteúdo.

Como funciona

  1. O usuário digita um endereço no navegador.
  2. O navegador envia uma requisição HTTP para o servidor.
  3. O servidor processa e envia uma resposta.
  4. O navegador mostra a página.

Métodos mais usados

  • GET - pede um recurso (ex: uma página).
  • POST - envia dados (ex: formulário).
  • PUT - atualiza um recurso.
  • DELETE - apaga um recurso.

Campos do request

Campo Significado
Request URL Endereço da página que foi pedida
Request Method Método usado. GET quer dizer que o navegador está pedindo a página
Status Code Resposta do servidor. 200 OK quer dizer que deu certo
Remote Address IP e porta do servidor. A porta 443 é a do HTTPS
Referrer Policy Regra que diz quanto do endereço de origem é enviado para outros sites

Campos do response

Campo Significado
cache-control Diz para o navegador não guardar a página em cache
connection keep-alive mantém a conexão aberta para os próximos pedidos
content-encoding A página veio compactada com gzip para ficar menor
content-type Tipo do conteúdo: uma página HTML em UTF-8
date Data e hora da resposta
expires Data em que a página "vence". Como é uma data antiga (1970), ela já vem vencida e não fica em cache
liferay-portal Sistema usado para fazer o site (Liferay)
pragma no-cache é uma forma antiga de pedir para não usar cache
server Programa do servidor: nginx rodando no Ubuntu
transfer-encoding chunked quer dizer que a página é enviada em pedaços
x-content-type-options nosniff impede o navegador de "adivinhar" o tipo do arquivo
x-frame-options SAMEORIGIN só deixa a página aparecer dentro de um iframe do próprio site

Alguns códigos de status

  • 200 - OK
  • 301 - Movido permanentemente
  • 404 - Não encontrado
  • 500 - Erro no servidor
